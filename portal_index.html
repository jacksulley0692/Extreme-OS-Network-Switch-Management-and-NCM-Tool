Field Engineer Switch Recovery & Replacement SOP

Console & TFTP Reference

Standard Operating Procedures for field workers replacing RMA switches, factory wiping hardware, and loading saved configurations.

Console Serial Settings
9600 baud, 8-N-1
RJ-45 Rollover or Micro-USB
Default Factory Login
admin / <empty password>
No password on clean unconfigure
Recommended Script Format
.xsf (ASCII CLI Script)
Directly executable via load config
1 Step 1: Clean Factory Wipe & Temporary Management IP 
# 1. Reset switch to clean factory default state
unconfigure switch all
reboot

# 2. After reboot, log in as 'admin' (hit enter for password)
# 3. Configure temporary IP to reach your TFTP backup server
configure vlan Default ipaddress 10.36.226.99 255.255.255.0
configure iproute add default 10.36.226.1
ping 10.36.226.7
2 Step 2: Pull .xsf Configuration from TFTP & Apply to Switch 
# 1. Download switch configuration script from TFTP server
tftp get 10.36.226.7 vr "VR-Default" SW-EDGE-EXOS-02.xsf

# 2. Execute configuration commands
load configuration SW-EDGE-EXOS-02.xsf

# 3. Commit running configuration to primary NVRAM
save configuration
use configuration primary
3 Step 3: Verification & Port Uplink Checks 
show vlan
show ports description
show iproute
show inline-power
show lldp neighbors
Console Serial Settings
9600 baud, 8-N-1
DB9 / RJ-45 Rollover
Default Factory Login
rwa / rwa (or admin / admin)
Read-Write-Admin privilege level
Config File Architecture
config.cfg (ASCII CLI format)
Loaded on boot via boot flags
1 Step 1: Enter Privileged Mode & Factory Zeroize 
enable
config t
boot config flags factory-default
reset -y
2 Step 2: Transfer Saved .cfg & Apply to Boot Flags 
enable
config t
interface Vlan 1
  ip address 10.36.226.99 255.255.255.0
  ip default-gateway 10.36.226.1
exit

# Copy backup to local NVRAM config.cfg and reboot
copy tftp 10.36.226.7 SW-FABRIC-VOSS-01.cfg config.cfg
boot config flags config-file config.cfg
reset -y
3 Step 3: Verify SPBM Fabric & Interfaces 
show isis spbm
show isis adjacency
show vlan i-sid
show interfaces gigabitEthernet
show ip route

Firmware Matching Warning: Always verify that the replacement hardware has the same major firmware revision (e.g. EXOS 31.x or VOSS 8.x) as the backup file before executing configuration scripts to prevent syntax mismatch.
